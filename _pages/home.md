### About the Project

C-3PE is an NSF-funded project aimed at enhancing introductory computer science education through the design and development of a comprehensive, personalized learning environment for programming students.

This is a collaborative effort between four institutions, leveraging AI-driven learning technologies and theoretical frameworks from learning sciences to create highly engaging CS learning experiences.
